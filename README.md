# Codex Plugin Directory

This repository contains Codex assistant assets.

## What is inside

- `catalyst-by-zoho/` - Plugin package focused on Catalyst by Zoho guidance.
- `.agents/` - Agent-related configuration files used by the workspace.

## Catalyst Plugin Layout

Inside `catalyst-by-zoho/`:

- `assets/` - Static assets used by the plugin.
- `skills/catalyst-by-zoho/SKILL.md` - Main skill definition and behavior instructions.
- `skills/catalyst-by-zoho/references/` - Topic-specific reference docs used on demand.
